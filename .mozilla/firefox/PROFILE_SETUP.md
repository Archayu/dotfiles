# Firefox Theming with Matugen

This directory contains the Firefox profile structure for dynamic theme integration with Matugen.

## ⚠️ Security Note

The actual `~/.mozilla/firefox/` directory is **NOT included** in this repository for security reasons. You need to set up Firefox theming on your local machine manually.

## 🔧 Setup Instructions

### 1. Find Your Firefox Profile

```bash
# List available Firefox profiles
ls ~/.mozilla/firefox/
# Output example: sbazuxhu.default-release/
```

### 2. Create Chrome Directory Structure

```bash
# Replace PROFILE_ID with your actual profile ID from above
mkdir -p ~/.mozilla/firefox/PROFILE_ID.default-release/chrome/websites
```

### 3. Create Required Files

**File: `~/.mozilla/firefox/PROFILE_ID.default-release/chrome/userChrome.css`**
```css
/* Browser UI Theming */
@import url("colors.css");

/* Optional: Add custom browser UI styling here */
```

**File: `~/.mozilla/firefox/PROFILE_ID.default-release/chrome/userContent.css`**
```css
/* Web Content Theming */
@import url("colors.css");
@import url("websites/index.css");

/* Optional: Add custom web content styling here */
```

### 4. Configure Matugen

The matugen template automatically generates:
- `~/.mozilla/firefox/PROFILE_ID.default-release/chrome/colors.css` (from `~/.config/matugen/templates/firefox.css`)
- `~/.mozilla/firefox/PROFILE_ID.default-release/chrome/websites/index.css` (via post_hook)

**Update `~/.config/matugen/config.toml`:**

```toml
[templates.firefox]
input_path = '~/.config/matugen/templates/firefox.css'
output_path = '~/.mozilla/firefox/PROFILE_ID.default-release/chrome/colors.css'
post_hook = 'PROFILE_DIR=$(find ~/.mozilla/firefox -maxdepth 1 -type d -name "*.default-release" | head -n 1); (echo "/* AUTO-GENERATED — DO NOT EDIT */"; find "$PROFILE_DIR/chrome/websites" -maxdepth 1 -type f -name "*.css" ! -name "index.css" | sort | while read -r file; do echo "@import url(\"$(basename "$file")\");"; done) > "$PROFILE_DIR/chrome/websites/index.css"'
```

### 5. Enable Firefox Theme Customization

1. Go to **about:config** in Firefox
2. Search for: `toolkit.legacyUserProfileCustomizations.stylesheets`
3. Set it to **true**

### 6. Generate Theme

```bash
# Generate Firefox theme from current wallpaper
matugen -i /path/to/wallpaper.jpg

# Or with pywalfox integration
pywalfox update
```

### 7. Restart Firefox

Close and reopen Firefox to apply the new theme. Changes should be instant without restart after the first setup.

## 📁 Directory Structure

```
~/.mozilla/firefox/
└── PROFILE_ID.default-release/
    └── chrome/
        ├── colors.css              (Generated by Matugen)
        ├── userChrome.css          (Manual - Browser UI)
        ├── userContent.css         (Manual - Web Content)
        └── websites/
            └── index.css           (Generated by Matugen post_hook)
```

## 🎨 What Gets Themed

The `colors.css` file generated by Matugen contains CSS custom properties (variables) that define:
- **Primary Colors:** Theme accent colors from wallpaper
- **Text Colors:** Foreground and background contrast
- **Surface Colors:** UI element backgrounds
- **Catppuccin Palette:** Full Mocha color palette for consistency

These variables can be used in `userChrome.css` and `userContent.css` like:

```css
:root {
  --color-primary: #f38ba8;
  --color-text: #cdd6f4;
  --color-background: #1e1e2e;
  /* ... more colors ... */
}

/* Usage example */
#nav-bar {
  background-color: var(--color-background) !important;
  color: var(--color-text) !important;
}
```

## 🔄 Auto-Update Theme

Add to your Hyprland autostart to update Firefox theme on startup:

```bash
# In ~/.config/hypr/autostart.conf
exec-once = pywalfox update
```

## ❌ Troubleshooting

**Theme not applying?**
- Check `about:config` setting: `toolkit.legacyUserProfileCustomizations.stylesheets = true`
- Verify file paths match your profile ID
- Firefox must be fully restarted (not just window close)

**Can't find profile directory?**
```bash
# Open Firefox profile directory directly
firefox -ProfileManager
# Or show in file manager
nautilus ~/.mozilla/firefox/
```

**Colors not updating?**
```bash
# Run matugen manually
matugen -i /path/to/wallpaper.jpg

# Check if files were generated
ls -la ~/.mozilla/firefox/PROFILE_ID.default-release/chrome/
```

## 📝 Notes

- Never commit your actual `~/.mozilla/firefox/` directory to version control (contains personal data)
- The template setup in `~/.config/matugen/templates/firefox.css` defines which colors are exported
- Matugen's post_hook automatically generates the `websites/index.css` file on each theme update
