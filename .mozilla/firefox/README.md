# 🦊 Firefox Theming Setup Guide

This directory provides **example files and instructions** for integrating Firefox with Matugen's dynamic color theming. Since the actual `~/.mozilla/firefox/` directory contains personal data, it's not included in the dotfiles repository for security reasons.

## 📁 Directory Structure

```
.mozilla/firefox/
├── PROFILE_SETUP.md                    # Main setup guide
└── chrome/
    ├── colors.css.example              # Color variables (generated by Matugen)
    ├── userChrome.css.example          # Browser UI styling (manual)
    ├── userContent.css.example         # Web content styling (manual)
    └── websites/
        └── index.css.example           # Website theme imports (generated)
```

## ⚡ Quick Start

### 1. **Find Your Firefox Profile ID**
```bash
ls ~/.mozilla/firefox/
# Example output: sbazuxhu.default-release/
```

### 2. **Create the Chrome Directory**
```bash
mkdir -p ~/.mozilla/firefox/PROFILE_ID.default-release/chrome/websites
```

### 3. **Copy Example Files**
```bash
# Copy and rename example files (remove .example extension)
cp ~/.config/dotfiles/.mozilla/firefox/chrome/colors.css.example \
   ~/.mozilla/firefox/PROFILE_ID.default-release/chrome/colors.css

cp ~/.config/dotfiles/.mozilla/firefox/chrome/userChrome.css.example \
   ~/.mozilla/firefox/PROFILE_ID.default-release/chrome/userChrome.css

cp ~/.config/dotfiles/.mozilla/firefox/chrome/userContent.css.example \
   ~/.mozilla/firefox/PROFILE_ID.default-release/chrome/userContent.css

cp ~/.config/dotfiles/.mozilla/firefox/chrome/websites/index.css.example \
   ~/.mozilla/firefox/PROFILE_ID.default-release/chrome/websites/index.css
```

### 4. **Enable CSS Customization**
Open `about:config` in Firefox and set:
```
toolkit.legacyUserProfileCustomizations.stylesheets = true
```

### 5. **Configure Matugen**
Update `~/.config/matugen/config.toml`:

```toml
[templates.firefox]
input_path = '~/.config/matugen/templates/firefox.css'
output_path = '~/.mozilla/firefox/PROFILE_ID.default-release/chrome/colors.css'
post_hook = 'PROFILE_DIR=$(find ~/.mozilla/firefox -maxdepth 1 -type d -name "*.default-release" | head -n 1); (echo "/* AUTO-GENERATED — DO NOT EDIT */"; find "$PROFILE_DIR/chrome/websites" -maxdepth 1 -type f -name "*.css" ! -name "index.css" | sort | while read -r file; do echo "@import url(\"$(basename "$file")\");"; done) > "$PROFILE_DIR/chrome/websites/index.css"'
```

### 6. **Generate Theme**
```bash
# Generate Firefox colors from your wallpaper
matugen -i /path/to/wallpaper.jpg

# Or use pywalfox
pywalfox update
```

### 7. **Restart Firefox**
Close and reopen Firefox. Your theme should now be applied!

## 📄 File Descriptions

### **colors.css** (Auto-Generated by Matugen)
Contains CSS custom properties (variables) defining the complete Catppuccin Mocha color palette plus dynamic wallpaper colors. Used by both `userChrome.css` and `userContent.css`.

**Variables included:**
- Primary colors (red, pink, mauve, blue, green, yellow, etc.)
- Neutral palette (text, backgrounds, borders)
- Special roles (overlay, surface, base)

### **userChrome.css** (Manual - Firefox Browser UI)
Styles the Firefox UI elements:
- Navigation bar, address bar
- Tabs and tab bar
- Sidebar
- Menus and buttons
- Scrollbars

This file imports `colors.css` and uses its variables for consistent theming.

### **userContent.css** (Manual - Web Content)
Styles web page content:
- Form elements (input, textarea, button)
- Links and text
- Code blocks
- Syntax highlighting
- Selection colors

This file imports both `colors.css` and `websites/index.css`.

### **websites/index.css** (Auto-Generated by Matugen post_hook)
Generated by the Matugen post_hook, this file imports site-specific CSS files from the `websites/` directory. You can add custom CSS files for individual websites here.

## 🎨 Customization

### **Modify Browser UI Theme**
Edit `~/.mozilla/firefox/PROFILE_ID.default-release/chrome/userChrome.css`:

```css
/* Example: Change tab height */
.tab-content {
  padding: 4px 8px !important;
  font-size: 11px !important;
}

/* Example: Custom toolbar background */
#nav-bar {
  background: linear-gradient(135deg, var(--color-surface0), var(--color-surface1)) !important;
}
```

### **Add Website-Specific Styling**
Create `~/.mozilla/firefox/PROFILE_ID.default-release/chrome/websites/github.css`:

```css
/* GitHub specific theming */
@import url("../colors.css");

.Header-link {
  color: var(--color-text) !important;
}

.form-control {
  background-color: var(--color-surface0) !important;
  border-color: var(--color-overlay1) !important;
  color: var(--color-text) !important;
}
```

The `websites/index.css` file will automatically import this when regenerated by Matugen.

## 🔄 Auto-Update Workflow

### **Hyprland Autostart**
Add to `~/.config/hypr/autostart.conf`:
```bash
exec-once = pywalfox update
```

### **Change Wallpaper Theme**
When you change wallpaper using `Super + Shift + W`:
```bash
~/.config/rofi/wallpaper/wall.sh
# Runs: matugen -i new-wallpaper.jpg
# Which updates Firefox colors automatically
```

## 🐛 Troubleshooting

| Issue | Solution |
|-------|----------|
| Theme not applying | Check `about:config`: `toolkit.legacyUserProfileCustomizations.stylesheets = true` |
| Colors not updating | Run `matugen -i wallpaper.jpg` manually |
| Files not found | Verify profile ID matches: `ls ~/.mozilla/firefox/` |
| Firefox won't start | Remove problematic CSS file and test incrementally |
| CSS syntax errors | Check browser console: `Ctrl+Shift+K` |

## 💡 Tips

1. **Test CSS Changes:** Use `about:support` → "Open Profile Folder" for quick access
2. **Preview Before Applying:** Use Firefox's Inspector (F12) to test CSS locally
3. **Keep Backups:** Before major changes, copy your chrome directory
4. **Use !important:** Some Firefox UI styles require `!important` flag
5. **Reload on Changes:** No restart needed - CSS changes apply instantly after closing/reopening

## 🔐 Security Note

**Do NOT commit these files to version control:**
- `~/.mozilla/firefox/` (contains browsing history, passwords, etc.)
- Any file in your actual Firefox profile

The `.example` files in this directory are for reference only. Use them as templates for your local setup.
